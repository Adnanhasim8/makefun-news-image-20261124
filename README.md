# Tuesday 24 November 2026 in one picture

A plain front page summing up Tuesday 24 November 2026's world news in a
single 1024×1024 image: the COP31 collapse as the lead, 11 more dated
stories across 8 regions, and 4 "also today" items — 12 dated stories in
all, with sources listed in [NEWS.md](NEWS.md).

## How to run

```sh
python3 main.py
```

Pure Python 3.13 standard library, no network at run time. It writes
`/output/entry.png` (1024×1024 PNG, ≤ 1 MiB, byte-identical across runs).
